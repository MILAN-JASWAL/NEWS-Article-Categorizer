# NEWS-Article-Categorizer
This project classifies news articles into four topics (World, Sports, Business, Sci/Tech) using the AG News dataset of 120,000 training and 7,600 test articles. Article titles and descriptions are converted to TF-IDF features (unigrams and bigrams) and used to train a Logistic Regression baseline and a Linear SVM, which reached 92.8% accuracy .
